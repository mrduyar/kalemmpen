# ✒️ Kalemm Pen Pro
**Ekran Üzeri Profesyonel Çizim ve Not Alma Aracı**

Kalemm Pen Pro, masaüstü ekranınız üzerinde şeffaf bir katman oluşturarak sunumlar, eğitimler veya tasarım incelemeleri sırasında doğrudan ekran üzerine çizim yapmanıza olanak tanıyan modern bir Windows uygulamasıdır.

## ✨ Özellikler
- **Çeşitli Çizim Araçları:** Kalem, Ok, Dikdörtgen, Elips ve Metin araçları.
- **Renk ve Kalınlık Kontrolü:** Kurumsal renk paleti ve ayarlanabilir uç kalınlığı.
- **Ekran Dondurma (Freeze Mode):** Ekran görüntüsünü sabitleyerek üzerinde statik çalışma imkanı.
- **Pano Entegrasyonu:** Panodaki görselleri doğrudan çizim alanına yapıştırma (Ctrl+V).
- **Saydam Kayıt:** Çizimlerinizi arka planı saydam PNG olarak kaydetme.
- **Aktif/Pasif Mod:** Çizim yaparken alttaki pencerelere tıklama imkanı (Click-through).
- **Hakkında Penceresi:** Kızıldağ Sedir ormanları temalı sanatsal bilgilendirme ekranı.

## 🛠️ Kurulum ve Çalıştırma
### Gereksinimler
- Python 3.8+
- PyQt6

### Çalıştırma
1. Bağımlılıkları yükleyin:
   ```bash
   pip install PyQt6
   ```
2. Uygulamayı başlatın:
   ```bash
   python kalemm_pen_pro.py
   ```

## ⌨️ Kısayollar
- **Ctrl + Z:** Son işlemi geri al.
- **Ctrl + V:** Panodan görsel yapıştır.
- **Ctrl + 1/2/3:** Hızlı renk değişimleri (Kırmızı, Yeşil, Mavi).
- **ESC:** Yazı modunu kapat veya uygulamadan çık.
